# Corporate Payroll System - UNAD 💼

## Descripción
Este proyecto es un Sistema de Nómina Empresarial desarrollado en Python para la **Fase 3 del curso de Programación (213023)**. El software aplica los pilares de la Programación Orientada a Objetos (POO) para gestionar el cálculo de salarios de diversos perfiles laborales de manera dinámica.

## Características Técnicas ⚙️
Para cumplir con los requerimientos técnicos, el proyecto implementa:
- **Herencia y Polimorfismo:** Estructura de clases que permite cálculos automáticos según el tipo de empleado.
- **Interfaz Gráfica (GUI):** Construida íntegramente en inglés utilizando la biblioteca estándar `tkinter`.
- **Optimización de UX:** Implementación de la función `Clear Form` que limpia automáticamente los campos al ejecutar cálculos o cambiar de selección, facilitando el seguimiento de pruebas.
- **Estructura Consolidada:** Todo el sistema reside en un único archivo (`corporate_payroll.py`) para agilizar la ejecución y revisión académica.

## Cómo ejecutar la aplicación ▶️

El proyecto utiliza únicamente librerías estándar de Python, por lo que no requiere instalación de dependencias externas.

1. Descargue el archivo `corporate_payroll.py`.
2. Abra una terminal o consola de comandos en la carpeta donde se encuentra el archivo.
3. Ejecute el programa con el siguiente comando:

python3 corporate_payroll.py
